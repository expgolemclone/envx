# Repository Rules

## GitHub issue work

- Base issue fixes on the fork's current `main` branch.
- Do not create an upstream pull request unless the user explicitly requests one.

## install

- 以下の例外以外の, 複数verの重複は禁止. 見つけたら最新に統一して.
- 例外
  - .NETは9/10
  - visual studioは2022に統一
  - .NET flameworkは4.6.1に統一
